## 蔵人桜
木の成長をリアルタイムで観察できるWEBサイトです。実時間で木が成長していくので、数年立つと木が大きく成長し、満開の桜を楽しむことができるでしょう。このサイトはClaudeを使って制作したため、蔵人桜（くろうどざくら）と名付けました。



# 設計
- 誰が見ても同じ木が描写されるようになっています。
- このサイトは静的サイトです。サーバ側で日数の計算を行わないため、github pagesなどのサービスでホストできランニングコストを抑えられます。
