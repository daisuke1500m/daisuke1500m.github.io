## 蔵人桜
桜の成長をリアルタイムで観察できるWEBサイトです。実時間で木の成長をシミュレートする実験的なサイトです。数年立つと木が大きく成長し、満開の桜を楽しむことができるでしょう。このサイトはClaudeを使って制作したため、蔵人桜（くろうどざくら）と名付けました。

## 設計
- このサイトは静的サイトです。そのためgithub pagesなどのサービスでホストできランニングコストを抑えられます。
- 木の生成はクライアント側で行われます。
- 誰がアクセスしても成長後の樹形は同じです。
- 描画される時刻にはアクセス時間が使用されます。
- 木の成長の再現にはSpace Colonizationアルゴリズムを使用しています。
